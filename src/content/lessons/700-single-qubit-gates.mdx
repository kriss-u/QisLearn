## Building a Circuit

So far you've built circuits the short way: `QuantumCircuit(1)` and go. Qiskit gives you a couple of other ways to do the same thing, and they're worth knowing before things get busier in later lessons.

**Give it a name.** Circuits (and the registers they're built from) can carry a `name`. It doesn't change what the circuit does; it just shows up wherever the circuit is drawn or inspected, which is handy once you're juggling more than one.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(1, name="my_first_circuit")
```

**Build it from a register.** Instead of just handing `QuantumCircuit` a number of qubits, you can first create a named `QuantumRegister` and pass that in instead. A register is just a named, sized group of qubits: right now that group has one qubit in it, but this is the pattern you'll use once circuits need more.

```python
from qiskit import QuantumCircuit, QuantumRegister

qr = QuantumRegister(1, "q")
qc = QuantumCircuit(qr, name="my_first_circuit")
```

Both snippets above produce an equivalent one-qubit circuit; try either style in the exercises below and the checker will accept it. The live circuit preview under each exercise will pick up the name and register label if you use them, so you can see the effect immediately.

## The Pauli-$X$ Gate

The **$X$ gate** is the quantum analogue of a classical NOT gate: it flips $|0\rangle \leftrightarrow |1\rangle$. On the Bloch sphere it is a 180-degree rotation about the $X$ axis.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(1)
qc.x(0)
```

There's a second way to write that last line. `qc.x(0)` is really just a shortcut for **appending a gate object** to the circuit, and that's a pattern that works for every gate Qiskit has:

```python
from qiskit import QuantumCircuit
from qiskit.circuit.library import XGate

qc = QuantumCircuit(1)
qc.append(XGate(), [0])
```

`.append(gate, qubits)` is the general mechanism; `.x()`, `.h()`, `.cx()` and friends are just convenience methods built on top of it. You'll see both styles used in the wild; use whichever reads better to you.

## The Hadamard Gate

The **Hadamard gate ($H$)** creates an equal superposition:

$$H|0\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle) = |+\rangle$$

On the Bloch sphere, $H$ rotates the state from the pole to the equator.
