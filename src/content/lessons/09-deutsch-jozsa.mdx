You now have every ingredient: uniform superposition (Lesson 6), interference that cancels exactly (Lesson 6), phase kickback (Lesson 7), and the oracle convention (Lesson 8). Deutsch-Jozsa combines all four into the first algorithm in this course with a *proven* quantum speedup over any classical approach.

## The Promise

You're handed an oracle for $f:\{0,1\}^n \to \{0,1\}$ with a guarantee: $f$ is either **constant** (same output for every input) or **balanced** (0 for exactly half the inputs, 1 for the other half). Nothing in between. Which one is it?

Classically, in the worst case you have to check more than half of all $2^n$ inputs before you can be sure — if the first $2^{n-1}$ all come back 0, you still can't rule out "balanced, and I just haven't seen a 1 yet" until one more check. Deutsch-Jozsa answers with certainty using a **single query** to the oracle.

## The Circuit

1. Start with $n$ input qubits at $|0\rangle$ and one ancilla. Set the ancilla to $|-\rangle$ (`X` then `H`) — the phase-kickback setup from Lesson 7.
2. `H` on every input qubit — uniform superposition over all $2^n$ inputs, queried "all at once."
3. One query to the oracle. Every input's $f(x)$ gets kicked back as a phase on that input's amplitude, thanks to the ancilla sitting in $|-\rangle$.
4. `H` again on the input qubits — turns the pattern of phases into an interference pattern in the probabilities.
5. Measure the input register only (ignore the ancilla).

If every input qubit reads $0$: $f$ is **constant**. If *any* input qubit reads $1$: $f$ is **balanced**. That's the whole algorithm.

### Constant Case: f(x) = 0

An oracle for the always-0 function does nothing at all — no gates. So step 3 is empty, and steps 2 and 4 become two `H`s in a row on each input qubit with nothing in between: exactly the H-then-H interference from Lesson 6. Every input qubit returns to $|0\rangle$ with certainty.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3)
qc.x(2)
qc.h([0, 1, 2])
# oracle for f(x) = 0 is empty — no gates
qc.h([0, 1])
```

### Balanced Case: f(x0, x1) = x0

A balanced function that depends only on $x_0$: the oracle is a single `CX` from qubit 0 into the ancilla (Lesson 8's linear-oracle recipe, using just one of the two inputs).

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3)
qc.x(2)
qc.h([0, 1, 2])
qc.cx(0, 2)   # oracle for f(x0, x1) = x0
qc.h([0, 1])
```
