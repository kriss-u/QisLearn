Recall from Unitary Matrices: every eigenvalue of a unitary $U$ has the form $e^{2\pi i\theta}$ for some real $\theta$, since unitary matrices only ever rotate an eigenvector's phase, never scale its length. **Quantum Phase Estimation** (QPE) is the algorithm that reads $\theta$ back out, given $U$ and one of its eigenvectors, using the Quantum Fourier Transform from last lesson as its final step.

## Why This Is Hard Classically

Nothing about $\theta$ is written down anywhere; it's an intrinsic property of how $U$ acts on a specific eigenvector, extractable only by actually applying $U$ (or its powers) and reading out interference patterns, exactly the kind of task quantum circuits are suited for and classical linear algebra on an exponentially large matrix is not. QPE is also the engine inside Shor's algorithm (two lessons from now): the "hidden number" Shor's algorithm extracts turns out to be exactly the $\theta$ that QPE estimates, for a specific, cleverly chosen $U$.

## The Circuit

Two registers: $n$ **counting qubits** (start at $|0\rangle$, will hold the answer), and an **eigenstate register** holding $|\psi\rangle$, an eigenvector of $U$ with $U|\psi\rangle = e^{2\pi i\theta}|\psi\rangle$.

1. $H$ on every counting qubit: uniform superposition, same starting move as every algorithm so far.
2. From counting qubit $k$ (weight $2^k$), apply **controlled-$U^{2^k}$** onto the eigenstate register. Since $|\psi\rangle$ is an eigenvector, this doesn't change $|\psi\rangle$ itself at all, it **kicks back** a phase of $e^{2\pi i\theta\cdot2^k}$ onto counting qubit $k$'s $|1\rangle$ amplitude, the exact same phase-kickback mechanism Deutsch-Jozsa was built on, just with a real (not just $\pm1$) phase this time.
3. Apply the **inverse QFT** to the counting register. The forward QFT (last lesson) turns a phase pattern *into* basis-state amplitudes; running it backwards does the opposite, turning the phase pattern step 2 just wrote onto the counting register back into a readable basis state.
4. Measure the counting register: the result is $\theta$, written out as an $n$-bit binary fraction (exact, if $\theta$ happens to be expressible in $n$ bits; an approximation otherwise).

## Worked Example: $\theta = 1/4$, Exactly

Let $U = P(\pi/2)$ (the $S$ gate) and $|\psi\rangle = |1\rangle$: $P(\pi/2)|1\rangle = e^{i\pi/2}|1\rangle = e^{2\pi i(1/4)}|1\rangle$, so $\theta = 1/4$, exactly representable in 2 bits ($0.01_2 = 1/4$). Use 2 counting qubits ($q_0$, $q_1$) and 1 eigenstate qubit ($q_2$, prepared in $|1\rangle$ with $X$):

- Controlled-$U^{2^0}$ from $q_0$: a single $CP(\pi/2)$.
- Controlled-$U^{2^1}$ from $q_1$: applying $U$ twice is the same as applying $U^2 = P(\pi)$ once (both times, only on the branch where the control is $|1\rangle$), so a single $CP(\pi)$.
- Inverse QFT on ($q_0$, $q_1$): the last lesson's QFT circuit, run in reverse with every angle negated: $SWAP$, $H$, $CP(-\pi/2)$, $H$.

```python
from qiskit import QuantumCircuit
import math

qc = QuantumCircuit(3)
qc.x(2)
qc.h(0)
qc.h(1)
qc.cp(math.pi / 2, 0, 2)
qc.cp(math.pi, 1, 2)
qc.swap(0, 1)
qc.h(0)
qc.cp(-math.pi / 2, 0, 1)
qc.h(1)
```
