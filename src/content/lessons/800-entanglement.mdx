## Two Qubits, Two Registers

Everything so far has been a single qubit, so the plain `QuantumCircuit(1)` form was enough. With two qubits, this is a good moment to reach for the register style from the previous lesson: a named `QuantumRegister` for the qubits, and (since real Qiskit circuits eventually need somewhere to put measurement results) a named `ClassicalRegister` for classical bits:

```python
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister

qr = QuantumRegister(2, "q")
cr = ClassicalRegister(2, "c")
qc = QuantumCircuit(qr, cr, name="bell_pair")
```

Nothing about *how gates get applied* changes: you still call `qc.h(0)`, `qc.cx(0, 1)`, etc. with plain qubit indices, register or no register. What the register buys you is a name: the circuit diagrams throughout this lesson use exactly this pattern, and you'll see the `q_0` / `q_1` wire labels and the `bell_pair` name it produces.

## The $CNOT$ Gate

**$CNOT$** (controlled-$X$) flips its target qubit only when the control qubit is $|1\rangle$. Combined with Hadamard, it produces **entanglement**: correlations that have no classical explanation.

```python
from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister

qr = QuantumRegister(2, "q")
cr = ClassicalRegister(2, "c")
qc = QuantumCircuit(qr, cr, name="bell_pair")
qc.h(0)
qc.cx(0, 1)
```
