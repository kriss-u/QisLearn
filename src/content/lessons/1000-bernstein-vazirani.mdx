Bernstein-Vazirani uses the *exact same circuit shape* as Deutsch-Jozsa. What changes is the oracle, and what you get out of it.

## The Problem

You're given an oracle that computes $f(x) = s \cdot x \pmod 2$ (the bitwise dot product, mod 2) for some hidden bitstring $s$ you don't know. Classically, recovering all $n$ bits of $s$ takes $n$ separate queries: query $x = 100\ldots0$ and you learn $s_0$, query $x=010\ldots0$ and you learn $s_1$, and so on, one bit per query. Bernstein-Vazirani recovers the *entire* string $s$ in a **single query**.

## The Oracle for a Linear f

This is precisely the linear-oracle recipe from Lesson 8: `CX` from input qubit $i$ into the ancilla, for every $i$ where $s_i = 1$. Skip the `CX` entirely for any $i$ where $s_i = 0$: that input never gets XORed in, exactly matching what $s \cdot x$ means.

Take the hidden string $s = (s_0, s_1) = (1, 1)$ over 2 input qubits, ancilla on qubit 2: every input bit matters, so both `CX`s are present:

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(3)
qc.x(2)
qc.h([0, 1, 2])
qc.cx(0, 2)   # s0 = 1
qc.cx(1, 2)   # s1 = 1
qc.h([0, 1])
```

Unlike Deutsch-Jozsa's "is it all-zero or not," here every input qubit lands on a definite, predictable value: qubit $i$ measures $s_i$, with certainty, for every $i$; one query and the whole string falls out. (Reading the basis-state label itself: this course writes kets as $|q_{n-1}\ldots q_1 q_0\rangle$, rightmost character is qubit 0, the convention from way back in Lesson 1's Bloch-sphere work. It's simplest to just read the per-qubit values straight off the circuit rather than the label string.)
