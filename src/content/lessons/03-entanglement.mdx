## The CNOT Gate

**CNOT** (controlled-X) flips its target qubit only when the control qubit is $|1\rangle$. Combined with Hadamard, it produces **entanglement** — correlations that have no classical explanation.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)
```

## The Bell State

Notice the two qubits are never independently on the Bloch sphere surface once entangled — only the joint state is pure.
