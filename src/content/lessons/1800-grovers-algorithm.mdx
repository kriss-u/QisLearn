Last lesson covered the geometry: the oracle and the diffusion operator each reflect the state about a different axis, and together they rotate it toward the marked answer. This lesson builds both as real gates and runs the whole thing on the smallest nontrivial case, searching 4 items, where you'll get to watch the rotation land **exactly** on the right answer.

## The Oracle, as a Gate

For a single marked item $|\omega\rangle$, the oracle just needs to flip the sign of that one basis state's amplitude and leave every other basis state alone. When $\omega = 11$ (both qubits marked), that's precisely what $CZ$ already does: flip sign exactly when both qubits read 1.

$$O|x\rangle = \begin{cases} -|x\rangle & x = \omega \\ \phantom{-}|x\rangle & x \neq \omega \end{cases}$$

## The Diffusion Operator, as Gates

$D = 2|s\rangle\langle s| - I$ reflects about the uniform superposition $|s\rangle$. The standard construction sandwiches a "flip sign of everything except $|00\rangle$" step between two layers of $H$: turn $|s\rangle$ back into $|00\rangle$ with $H^{\otimes n}$, flip every state's sign *except* $|00\rangle$ (equivalently, up to an unobservable global phase, flip the sign of *only* $|00\rangle$), then undo the $H$s. Flipping the sign of $|00\rangle$ specifically is $X$ on every qubit (remaps $|00\rangle\leftrightarrow|11\rangle$), then the same $CZ$ used above (now catching the remapped $|11\rangle$), then $X$ again to undo the remap:

$$D = H^{\otimes n}\,X^{\otimes n}\,(\text{CZ})\,X^{\otimes n}\,H^{\otimes n}$$

## The Full Circuit, N = 4

Search 2 qubits (4 possible items) for $\omega = 11$. With $\sin\theta = 1/\sqrt4 = 1/2$, $\theta = 30°$; one Grover iteration lands the state at $(2\cdot1+1)\cdot30° = 90°$, giving $\sin^2(90°) = 1$: a single iteration finds the answer with **certainty**, no other outcome is even possible. This exact-success case only happens at $N=4$; larger $N$ needs $k_{\text{opt}}=\left\lfloor\frac{\pi}{4}\sqrt N\right\rfloor$ iterations and lands close to, but not exactly at, probability 1.

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(2)
qc.h([0, 1])       # uniform superposition over 00, 01, 10, 11
qc.cz(0, 1)         # oracle: flip sign of |11> (the marked item)
qc.h([0, 1])        # diffusion operator starts here
qc.x([0, 1])
qc.cz(0, 1)
qc.x([0, 1])
qc.h([0, 1])
```

## Why the Oracle Needs to Change for a Different Target

This lesson's oracle only marks $|11\rangle$, because that's exactly what $CZ$ flips the sign of. To mark a different target, say $|01\rangle$, sandwich the same $CZ$ between $X$ gates on whichever qubits should read 0 in the target (here, qubit 0): $X$ on qubit 0 remaps $01\to11$, $CZ$ catches it, $X$ undoes the remap, exactly the same trick the diffusion operator's own construction already used above to target $|00\rangle$ instead of $|11\rangle$.
